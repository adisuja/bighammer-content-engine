| Design DNA — reusable playbook |  |
| Source | Distilled from a full-resolution audit of 155 elite LinkedIn carousels (Alex Vacca/ColdIQ, Harry @marketingharry, Austin Belcak/Cultivated Culture, Patrick James Cumming/Ad Juice+KlientBoost), 2026-07-09. This is the bar the engine must SURPASS 2-3×. Per-post teardowns live in the 'Design · …' columns of the LinkedIn Creator Taxonomy tab. |
|  |  |
| THE 11 CRAFT LAWS | What makes them elite |
| Law 1 — Concept-first: one ownable metaphor per post. | A bespoke visual idea keyed to the thesis — iceberg, stop sign, escalating crowd, tarot deck, Nokia LCD, juice-squeeze, football field, game-board "Algoroth", brain. Design serves the concept. (NOT a template with text poured in.) |
| Law 2 — Bespoke information architecture — one skin, N diagram engines. | Each post is a structurally correct diagram: radial hub-and-spoke, geographic pin-map, true 2×2 w/ rotated axes, Venn w/ blended intersections, 3D funnel, pyramid w/ slope-rotated labels, decision tree w/ elbow connectors, isotype/waffle grid, day-1→N timeline rail, org-chart, CLI man-page, emotional line-chart, dense dashboard, editorial magazine double-truck. Real geometry + connector routing. |
| Law 3 — Text integrated INTO/ONTO objects, not floated over. | Headline set inside the stop sign, on a Nokia LCD, on a ribbon banner, masked onto a lit 3D funnel, rotated along pyramid slopes, seated in Venn intersections, rendered as a UI text-selection. The type IS the artwork. |
| Law 4 — Real typography system. | Condensed-black display (Anton/Druk/Impact-class, ALL-CAPS, tight tracking) + humanist bold headers + clean body (Inter/Geist) + monospace code chips. Signature devices: two-tone hero split (line 1 dark / line 2 accent), one-word highlight-box/pill, italic accent word (the year, "Matrix"), light/bold weight-swap in one line. Register-switch (serif, marker/handwritten, pixel, LCD) per concept. (NOT default Inter everywhere.) |
| Law 5 — Semantic color = data encoding, not decoration. | green=good/go, red=bad/stop, amber=caution; per-branch/tier/section hues echoed across connectors + badges + card borders + accent bars; Venn blends; funnel-depth gradient; brain-lobe↔card-border mapping. ONE accent held with discipline (Ad Juice mono-lime, ColdIQ blue), rotated per taxonomy but never rainbow-noise. |
| Law 6 — Persistent brand furniture every slide. | Identity chip (avatar + name + @handle/domain, verified check / fake-tweet card), micro brand-bar, recurring CTA component ("SAVE THIS"/"REPOST"/"Comment X and I'll send it"), page indicators, footer logo lockup, source citations, "concept inspired by @…" credits. |
| Law 7 — Imagery = proof + premium, never filler. | Real brand logos in consistent rounded-tile/pin containers (collision-free, correct color, 20-50 per poster). Real product/UI mockups (terminal, Slack, IDE w/ syntax highlighting, dashboards) annotated w/ hand-drawn arrows + callouts. Premium 3D/glass/copper/clay hero renders + pixel-arcade wordmarks. Grade-matched recurring characters across a set (ginger cat, chihuahua scholar). Owned B\&W founder photography + card-over-photo composites. Surreal literal-metaphor photos (goldfish-in-jelly, TV-head). |
| Law 8 — Density with discipline. | 22-46+ items on one poster stay scannable via numbering rhythm, per-section color, strict gutter/card grids, \`→ monospace\` detail rows. Save-bait density = high perceived effort. |
| Law 9 — Per-slide layout variety + energy arc. | Cinematic movie-poster cover → editorial whitespace-heavy interiors → poster CTA. One poster can hold 6+ distinct internal micro-layouts. NOT 8 slides at one visual volume. |
| Law 10 — Deliberate rawness as a valid mode. | Raw iPhone selfies, annotated screenshots ("lo-fi proof" — Patrick's Ad Type \#5), napkin sketches, hand-drawn marker worlds. Format mimicry: fake magazine spread, fake LinkedIn Featured, fake TV lower-third. Knowing when to look handmade beats the bot. |
| Law 11 — Tactile/analog realism. | Paper/speckle/film-grain/starfield/kraft texture on flat fills (never pure \#FFF/\#000), real cast-shadow overlays, ransom-note cut letters, hand-lettering irregularity, sticky-note grids. Kills the "flat vector template" tell. |
|  |  |
| ARCHETYPE LIBRARY | radial hub-and-spoke · geographic pin-map · true 2×2 (rotated axes) · Venn (blended intersections) · 3D funnel · pyramid (slope-rotated labels) · decision tree (elbow connectors) · isotype/waffle grid · day-1→N timeline rail · org-chart · CLI man-page/cheat-sheet · emotional line-chart · dense dashboard · editorial magazine double-truck · serpentine game-board · photo+overlaid-card composite · fake-tweet card · knockout comparison (❌/✅) · mind-map · iceberg / literal-metaphor cover · raw screenshot/selfie (lo-fi proof) |
| REPEATING MICRO-STRUCTURES | Signals/Performance/Action · Retire/Run/Proof · Play/Proof/Failure-Mode · Formula/Note/Example · number-badge → colored caps subhead → italic support → tool-logo chip → dark DO/PASTE action bar. |
| THE 2-3× BAR (hardest to replicate) | Concept→metaphor ideation · correct diagram geometry w/ connector routing · text-on-object typesetting · grade-matched character/world continuity across a generated set · collision-free real-logo curation · semantic color reasoning · magazine-grade editorial typesetting · knowing when to be raw. |

| PER-CREATOR SYSTEMS | The four house systems behind the corpus |
| Alex Vacca / ColdIQ — house system | Near-black navy/space bg (\#0A0E17) + starfield texture; cream-white (\#F5F0E1) condensed ALL-CAPS display grotesk with an italic accent word (usually the year '2026') and ONE word in a highlight-box/pill; humanist sans body. Reused furniture: 'Alex Vacca \| coldiq.com' identity pill, small-caps kicker, numbered section badges, source-citation microtext, 'Comment X and I'll send it' CTA pill, ColdIQ footer lockup, cutout co-author portraits. Imagery = proof: real SaaS logos in rounded chips, UI mockups, premium 3D/pixel mascots. Every poster is a DISTINCT information architecture (radial hub, geo pin-map, rotated-axis 2×2, flowchart-with-loop, editorial block grid). Semantic color (green=hot/go, red=cold/stop) carried across pyramid+badges+bars. Density held legible by strict card grids + connector routing. The elite bar of the whole corpus. |
| Harry Dry / @marketinghary — many universes, one system | ONE identity system flexed across many art-directed 'universes' (cinematic-dark, clean-white editorial, kraft-paper serif mind-map, retro-game, tarot, 3D-chrome, traffic-light semantic). Constants: '@marketingharry' identity bar top-left; oversized ALL-CAPS two-color cover hook; highlight-box verb system (word burned into a solid accent box); ONE loud accent per post (LinkedIn-blue / burnt-orange / acid-green / hot-pink) on a B\&W base; finger-point emoji swipe cue; save-bait dense deliverable slide (31-day calendar, 30-logo pyramid). Imagery engine = AI hero art: recurring anthropomorphic cat mascots + surreal literal metaphors (goldfish-in-jelly, gas-mask cat) + personified 3D brand-logo mascots. Covers are formulaic/cloneable; the art-directed grade-matched character continuity + kraft-paper mind-map are what's genuinely bespoke. |
| Austin Belcak / Cultivated Culture — four coordinated templates | One creator running FOUR template families (the system IS the lesson, not the look). Signatures: speckle/film-grain paper texture on nearly every surface (never flat \#FFF/\#000); highlight-box kicker language (blue=insight, coral/red=warning/sales, green=checklist); persistent verified identity header (avatar + name + blue check + @handle) as built-in watermark; two accent palettes — blue \#2E6FF2 (educational/AI) vs coral-red \#F1615E (coaching/sales) — never muddied. Owned B\&W editorial founder photography + raw selfies + card-over-photo composites; annotated real IDE/UI screenshots as proof; 'CULTIVATED CULTURE' footer lockup. Deliberately LOW-FI: many 'posts' are raw iPhone photos or curated news screenshots (authenticity/volume over polish). Weaknesses to beat: body type is default Poppins/Gotham (not bespoke), interior list slides near-identical, hard-edged rectangular highlight boxes. |
| Patrick James Cumming — lo-fi-proof + Ad Juice / Kitchen brands | One operator, THREE deliberate brand systems matched to intent: Ad Juice (grotesk-minimal, lime reversed-highlight), KlientBoost 'Kitchen' (playful coral+purple sticker/tab system), and off-brand meme+magazine mimicry. Signature atom: text reversed out of a colored box/bar (lime=Ad Juice, purple=Kitchen). Info-design literacy: isotype waffle grids, vertical flow-maps with arrows, day-1→90 progress rails — data becomes layout. Format mimicry: faux print magazine, faux LinkedIn Featured, faux TV breaking-news. Real third-party logos + real screenshots (SERPs, dashboards, $0 earnings) as credibility currency; monospace code chips for UTM/formulas; 3D tagline-metaphor renders ('squeeze the juice pouch'). 'Lo-fi proof' (annotated raw screenshots) is a deliberate valid mode. Moat = editorial + infographic literacy and multi-brand discipline, not raw polish. |
