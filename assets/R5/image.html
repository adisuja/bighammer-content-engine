Price all four costs
before you move a job

Most migration business cases only price the first one.Richard Lawrence

1. Target compute

  • Size instances from real CPU datap95 utilisation, not last year's cluster size
  • Spot or preemptible nodes where a retry is cheap
  • Storage, and egress if data crosses clouds
  • Committed use discounts you'd actually hit

3. Migration effort

  • Code conversiondbutils calls, the dlt module, three-part table names
  • Orchestration rewired: schedules, retries, alerts
  • Access, tags and governance rebuilt on the target
  • Testing time per job, not per project

2. Platform fee

  • Dataproc: $0.010 per vCPU houron top of the Compute Engine bill
  • EMR: a per-instance uplifte.g. $0.048 an hour on m5.xlarge, us-east-1
  • Serverless priced per unit insteadDataproc Serverless per DCU hour; EMR Serverless per vCPU and GB hour
fee = vCPUs × hours × rate

4. The dual-run period

  • Both platforms billed while you prove parity
  • 5 checks per jobcounts, schema, nulls, aggregates, row-level
  • Cut over in waves, lowest risk first
  • Budget weeks, not days
  • Decommission the old job on a dateor you pay for both indefinitely
